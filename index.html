How this dashboard is built

Source: eth_getLogs on the public Robinhood Chain RPC (https://rpc.mainnet.chain.robinhood.com), filtering the StoaRouter contract (0x2F2804fad735a38015650f32f95Ad5E08D6B3eE5) for the Routed event (topic0 0x2bbce25631e8fa58085b7ea5929726c3acdf2df8d6b1f099eb32fb7425a4f6da), from the deployment block 114,244,443 to block 119,487,667. The same query as Dune SQL: SELECT * FROM robinhood.logs WHERE contract_address = 0x2F28… AND topic0 = 0x2bbc…. Raw data: data/swaps.json · data/tokens.json · Query scripts: fetch_swaps_parallel.py, fetch_tokens.py. All figures on this page are computed in the browser from that raw data (see the embedded STOA_DATA object); the static numbers above are the same values, shown when JavaScript is off. Update: re-run the scripts and replace data/swaps.json.

Built for the Stoa build bounty (stoadex.com/build#bounties). Code: MIT, open source. Referrer / payout address: 0xc8511eD5B820E99889B168A4167FccDF73a9a2A2 (triv). Stoa charges a flat 2 bps protocol fee; the referrer earns 10% of it on swaps made through the link above. Not affiliated with Stoa — an independent public dashboard.
